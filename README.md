# Urban Threads Store

Urban Threads Store is a simple e-commerce website for trendy streetwear. Users can browse products, sign up, log in, and manage their shopping cart.

Built using HTML, CSS, JavaScript, Firebase Firestore, and Firebase Authentication.

## Features

* User Sign Up and Login
* View products from Firebase Firestore
* Add to Cart and Remove from Cart
* Cart total calculation
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript
* Firebase Firestore
* Firebase Authentication
* GitHub
* Netlify
